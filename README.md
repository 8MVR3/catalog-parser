# Парсер каталога в Excel

Учебный, но полноценный парсер: собирает весь каталог книжного магазина [books.toscrape.com](https://books.toscrape.com) — сайта, созданного специально для тренировки парсинга, — и сохраняет его в Excel со сводкой.

![Результат](docs/result.png)

## Что собирает

1000 книг с 50 страниц: название, категория, цена, рейтинг, наличие и количество на складе, артикул (UPC) и ссылка. Категорию и остаток парсер берёт со страницы каждой книги, поэтому проходит и по карточкам.

## Как устроено

- requests с повторами при сбоях и паузой между запросами, чтобы не нагружать сайт;
- BeautifulSoup разбирает список и карточки, переходы по страницам — по ссылке «next», а не по угаданным номерам;
- дубли отсекаются по артикулу, пустые поля проверяются перед сохранением;
- в Excel два листа: данные и сводка по категориям, которая считается формулами и пересчитывается сама при правках.

## Запуск

```
pip install -r requirements.txt
python parse_books.py          # весь каталог, около 10 минут
python parse_books.py --fast   # только списки, без карточек, около минуты
```

Пример результата — `examples/Книги.xlsx`: 1000 книг, 0 дублей и пустых полей.

## Тесты

```
pip install pytest
pytest
```

Тест подменяет сайт локальными страницами и проверяет пагинацию, разбор полей и сохранение.
