# catalog-parser

Парсер учебного магазина books.toscrape.com: весь каталог в Excel со сводкой по категориям.

## Структура

- `parse_books.py` — `get` с повторами при сбоях, `parse_list` обходит страницы по ссылке «next», `parse_details` берёт категорию и остаток из карточки, `save` пишет Excel с листом данных и сводкой на формулах.
- `tests/test_parser.py` — подменяет сайт локальными страницами и проверяет пагинацию, поля и сохранение.

## Команды

```
pip install -r requirements.txt
python parse_books.py          # весь каталог, около 10 минут
python parse_books.py --fast   # только списки, без карточек
pytest
```

## Правила

- Пауза между запросами обязательна, не убирать её ради скорости.
- Дубли отсекаются по артикулу (UPC), пустые поля проверяются перед сохранением.
- Внутри кода поля называются по-английски (`title`, `price`, `category`), русские названия появляются только в Excel.
- Парсер рассчитан на учебный сайт. Обход защиты чужих сайтов сюда не добавлять.
